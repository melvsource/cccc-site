How to add a PDF

Place your PDF in docs/assets/pdfs/. Then open resources.html, find a placeholder card, remove the placeholder class, and set href="/assets/pdfs/your-file.pdf". Change the name and description. Save and push to GitHub.

How to add a link

Find a link-card placeholder block in the Recommended Links section. Remove the placeholder class, set the real href, and fill in the name, description, and URL display text. Save and push.
